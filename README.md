# 🚨 Disaster Response Allocator

A disaster response management dashboard designed to help monitor emergencies, manage incident reports, and track emergency resources through a centralized interface.

## 📌 About the Project

Disaster Response Allocator is a web-based dashboard developed to organize disaster-related incidents and provide a simple interface for monitoring emergency situations.

The project focuses on incident reporting, priority monitoring, incident resolution, and emergency resource tracking.

This project is being developed as part of my learning journey in web development and AI & Machine Learning.
## 📸 Project Preview

![Disaster Response Allocator Dashboard](dashboard.png)

## ✨ Features

- 📊 Interactive disaster response dashboard
- 🚨 Incident monitoring and management
- 🔍 Search incidents by location or text
- 🎯 Filter incidents based on priority
- 📝 Submit new incident reports
- ✅ Mark incidents as resolved
- 📈 Dynamic dashboard statistics
- 💾 Save incident data using browser localStorage
- 🚑 Emergency resource tracking interface

## 🛠️ Technologies Used

- React
- JavaScript
- Vite
- HTML
- CSS
- Browser localStorage
- Git & GitHub

## 🖥️ Current Project Status

The current version includes a functional frontend dashboard with incident reporting, filtering, resolution, and browser-based data persistence.

The project currently uses sample emergency resource data.

Features such as backend integration, cloud database storage, AI-powered incident analysis, map integration, and resource assignment are planned for future development.

## ⚙️ How to Run the Project

### Prerequisites

- Node.js
- npm

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/HeenaKousar555/disaster-response-allocator.git
   ```

2. Navigate to the frontend project folder:

   ```bash
   cd disaster-response-allocator/frontend/disaster-response-allocator
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
